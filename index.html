Install everything on Windows

Paste this in PowerShell once. It downloads every tool into %USERPROFILE%\ChatHub, adds a desktop shortcut and opens this page offline. Run it again any time to update.

powershell -ExecutionPolicy Bypass -c "iwr https://raw.githubusercontent.com/spencerrios64/chathub/main/install.ps1 -UseBasicParsing | iex"
